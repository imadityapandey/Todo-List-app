# 📝 Interactive Task Organizer (To-Do List App)

A fast, responsive, and lightweight task management web application designed to help users prioritize study routines, track daily goals, and organize project milestones efficiently.

![App Preview](https://img.shields.io/badge/Status-Completed-success)
![Built With](https://img.shields.io/badge/Built%20With-React%20%7C%20TypeScript%20%7C%20Vite-blue)

---

## ✨ Features

* **Task Prioritization:** Categorize daily tasks with **Low**, **Medium**, and **High** priority tags.
* **Smart Filtering:** Effortlessly switch between **All**, **Active**, and **Completed** task views.
* **Data Persistence:** Automatically saves your tasks locally using browser **LocalStorage**, ensuring no data is lost on page refresh.
* **Bulk Actions:** Quick option to mark all active tasks as complete or clear finished tasks.
* **Responsive UI:** Clean, distraction-free user interface built for both desktop and mobile views.

---

## 🛠️ Tech Stack

* **Frontend Library:** React
* **Language:** TypeScript
* **Build Tool:** Vite
* **Styling:** Tailwind CSS / CSS Modules
* **Icons:** Lucide React
